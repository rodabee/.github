# RodaBee

![RodaBee](../assets/rodabee-logo.png)

RodaBee is organizing its product, platform, and operational tooling into a dedicated engineering workspace.

## Core Repositories

- [`rodabee-backend`](https://github.com/rodabee/rodabee-backend) - API, GraphQL, business logic, and platform modules.
- [`buyers-web`](https://github.com/rodabee/buyers-web) - public buyer/catalog experience.
- [`backoffice`](https://github.com/rodabee/backoffice) - internal operations and business controls.
- [`infra`](https://github.com/rodabee/infra) - infrastructure, environments, and deployment foundation.
- [`faas`](https://github.com/rodabee/faas) - background jobs and serverless workflows.
- [`migration-plan`](https://github.com/rodabee/migration-plan) - migration roadmap, architecture decisions, runbooks, and optimization plan.

## Migration Direction

The migration is focused on making RodaBee simpler, faster, and easier to operate:

- one GitHub organization;
- clearer ownership per app;
- safer CI/CD;
- lower infrastructure waste;
- cleaner module boundaries;
- faster buyers-web experience;
- more useful backoffice controls;
- observable deploys with rollback.
